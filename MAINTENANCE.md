# Maintenance

One person maintains BACpack. This page says what to expect, so you can decide how far to rely on it.

## Releases

There is no fixed schedule. Bug fixes ship in patch releases (`1.0.x`), usually several at a time. Feature releases (`1.x.0`) come roughly every one to two months. [CHANGELOG.md](CHANGELOG.md) lists every release, and each one opens the data an earlier 1.x release saved.

## Issues

Response is best effort, usually within a week, with no guarantee. Questions and setup help go in [Discussions](https://github.com/dmpatters/BACpack/discussions). Report security problems through [SECURITY.md](SECURITY.md), not public issues.

## The bacpypes3 dependency

BACpack's BACnet stack is [bacpypes3](https://github.com/JoelBender/BACpypes3), pinned to one release, 0.0.106.

## If the project stops

BACpack is MIT licensed ([LICENSE](LICENSE)). Anyone may fork it and carry it on.
