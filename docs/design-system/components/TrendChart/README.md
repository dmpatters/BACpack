The trend view for an object's logged history: a time-range picker, then one line chart per object with a crosshair tooltip and a table twin.

**Markup.** One range picker above everything: `div.bp-chart-range` with a `bp-segmented` radio group (1 h, 6 h, 24 h, 7 d, 30 d, Custom) and a help note naming the zone ("Times in UTC"). Charts in `div.bp-chart-stack`, one `section.bp-chart` per object: `div.bp-chart__head` (`h3.bp-chart__title` with `span.bp-chart__sub` for id and unit, a ghost "View as table" button), `div.bp-chart__plot` > `div.bp-chart__inner` > an `svg.bp-chart__svg` and, on hover or focus, `div.bp-tip[role="tooltip"]`, then `div.bp-chart__foot`. SVG parts use the classes `bp-chart__grid`, `__tick`, `__text`, `__area`, `__line`, `__dot`, `__cross`, `__label`; their colors come from the tokens.

**The consumer provides** the samples (timestamp, value), the range, the unit, and the draw code. The chart fills its card's width; the plot scrolls sideways inside the card below about 560px rather than shrinking its text.

- **One object per chart, one unit per chart.** Never add a second y-axis. To compare objects, stack separate charts that share the range above; different units are always separate charts.
- **Colors.** A single series uses `accent` for the 2px line (round joins) and a 10% wash of it for the area. Text, labels and tooltips use text tokens, never the series color. Grid lines are `border` hairlines, solid, with value ticks in `bp-chart__text` (mono, muted).
- **Analog objects** draw a line. **Binary and multi-state objects** draw a step line (a value holds until the next sample) with the state names, not numbers, as y-axis labels (On / Off, or Off / Low / Medium / High).
- **Label sparingly.** Label only the latest value at the line's end, with its unit, in `bp-chart__label`; the end dot has a 2px `surface` ring. Never print a number on every point.
- **Time axis in UTC**, `HH:MM` ticks at even intervals for the range, with the date shown under the tick at midnight. Say "Times in UTC" beside the picker; if the person picks local time, say "local" there and on the axis. Don't mix zones on one screen.
- **Gaps are shown as gaps, for interval trends.** When an interval trend is missing samples, break the line and area, and say so in the footer ("no samples 00:00–01:00"). Never join across a gap.  **COV trends have no gaps**: samples are irregular by nature, so a quiet stretch cannot be told from a stopped device.  Draw a step line that holds the last value until the next change, and say so in the footer ("Change-of-value trend: the value holds until the next change").
- **Hover and focus.** A vertical `bp-chart__cross` snaps to the nearest sample; the `bp-tip` shows the value first (strong, mono, with a short line key in the series color) and the time below it (muted). The hover target is the whole plot height with at least 24px of width per sample, not the 2px line. Keyboard: arrow keys move between samples and show the same tooltip.
- **A table twin for every chart.** "View as table" swaps in a `DataTable` of time and value (newest first), so no value depends on hovering.
- **Range changes keep the frame.** While new data loads, add `bp-chart--stale` (previous render at half opacity) instead of a skeleton; a failed load shows an `AsyncState` error under the picker and keeps the previous chart marked "previous result".
- **Custom range** reveals two date-time inputs (UTC) in the same row as the picker; the picker's presets stay first.
- The footer states sample count and interval and, when a sample cap or retention trims the range, says so ("showing the latest 10,000 samples").
- Don't: use a fixed 700px chart, a pie or dual axis, dashed gridlines, a legend for a single series, or color alone to mark a gap.
